# Canada Food Shock Stress Test

An interactive prototype showing how shocks to Canada's food system could unfold, and how much early action could avoid compared with acting late or doing nothing.

**Live page:** https://bdzion.github.io/canada-food-stress-test/

**User guide:** https://bdzion.github.io/canada-food-stress-test/guide.html

Developed at the Arrell Food Institute (AFI), University of Guelph, as a discussion prototype for a long-term research program on anticipatory decision-making for food-system shocks. It builds on AFI's 2026 Canada Agri-Food Chokepoint Audit.

## What it shows

| View | Content |
| --- | --- |
| Integrated stress test | Four modelled shocks in one year; losses from doing nothing, acting four weeks late, or acting early; extra losses when shocks overlap; value of a joint response playbook |
| Shock register | Fifteen real and emerging shocks, each with a recent Canadian event, ranked by a preliminary priority score |
| Rail or port shutdown | Corridor closure from a labour dispute, flood or wildfire |
| Phosphate before seeding | Fertilizer import shortfall ahead of spring seeding |
| Cyberattack on distribution | A major grocery distributor taken offline |
| Avian influenza | A regional wave of highly pathogenic avian influenza in poultry |

## Important caveats

- **Illustrative only.** The models are stylized and use stated assumptions. They are not forecasts.
- Every assumption is listed in the page's "Assumptions and sources" table and marked as sourced or illustrative.
- Shock rankings are the authors' preliminary judgement. Phase 1 of the program replaces them with a structured expert ranking.

## Structure

The site has two self-contained pages with no build step: `index.html` (the interactive stress test) and `guide.html` (the user guide: plain-language definitions, a decision workflow, back-end work and evidence on effectiveness). `preview.png` is the image shown when the link is shared. Fonts load from Google Fonts. GitHub Pages serves it from the `main` branch root.
